dsh-lan-guard `0.4.5` · 已验证 DeepSeek Harness `0.2.0-rc.1`、`0.1.7-rc.2`

<h3 id="cn-v0.4.5">📱 长会话不再「只显示一小段」：裁剪补偿不再提前收工</h3>

0.4.4 的裁剪补偿只在页面打开后的一小段时间里找被裁的层，而长会话的正文是**后挂载**的：官方滚动层先拿到一点点可滚范围，补偿就判定「已经正常」收工；等正文真正进来时，那层 `overflow:hidden` 再也没人放行 —— 手机上看到的就是「只有一小段、拖不到底」，而同一个会话在桌面却正常。

`mobileScrollFix` 现在把「官方滚动层暂时可滚」当作中间态：继续在既有的每 1.5 秒、最多 30 次窗口内侦测延迟出现的裁剪层，直到补偿成功（或回退分支成功）才收工。补偿照旧自检「可滚范围是否真的变大」，无效则整体回退，页面保持与官方一致。

真机实测（iPhone 16 Pro Max / iOS 27，经代理 3081，同一长会话）：

| | 修复前 | 修复后 |
| --- | --- | --- |
| 官方滚动层 client / scroll | 668 / 1004 | 668 / 7557 |
| 可滚范围 | **336px** | **6889px** |
| 滚动层内部被裁的层 | 1 层（`EvIC1a_frame`，796 高、`overflow:hidden`） | **0 层** |

- 只影响 DSH `0.2.0-rc.1` 上的窄屏移动端长会话：脚本仅在窄屏 + 移动 UA 下运行，宽屏与桌面不受影响。
- 只动官方滚动层**内部**那一层：不新建滚动容器、不改官方其余 UI；官方「回到底部」按钮仍在屏内。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启一次 dsh 生效。

<h3 id="en-v0.4.5">📱 Long sessions no longer show "just a fragment": the clip compensation stops giving up early</h3>

The 0.4.4 clip compensation only looked for the clipped layer during a short window after the page opened, but a long transcript **hydrates later**: the official scroller picks up a small scroll range first, the compensation declared the page healthy and stopped, and by the time the real content arrived nobody released the `overflow:hidden` layer — on the phone that reads as "just a fragment, cannot reach the bottom", while the same session is fine on desktop.

`mobileScrollFix` now treats "the official scroller is temporarily scrollable" as an intermediate state: it keeps looking for a late-appearing clipped layer inside the existing every-1.5s, at-most-30-tries window, and only stops once the compensation succeeds (or the fallback path succeeds). The compensation still self-checks that the scroll range actually grew and reverts wholesale when it did not, leaving the page identical to stock.

Measured on device (iPhone 16 Pro Max / iOS 27, through the proxy on 3081, same long session):

| | Before | After |
| --- | --- | --- |
| Official scroller client / scroll | 668 / 1004 | 668 / 7557 |
| Scroll range | **336px** | **6889px** |
| Clipped layers inside the scroller | 1 (`EvIC1a_frame`, 796 tall, `overflow:hidden`) | **0** |

- Affects only narrow-screen long sessions on DSH `0.2.0-rc.1`: the script runs on narrow viewports with a mobile UA only, so wide screens and desktop are untouched.
- Only the layer *inside* the official scroller is touched: no extra scroll container, no restyling of the official UI; the official "back to bottom" button stays on screen.
