dsh-lan-guard `0.4.6` · 已验证 DeepSeek Harness `0.2.0-rc.2`

<h3 id="cn-v0.4.6">🔌 兼容 DeepSeek Harness 0.2.0-rc.2</h3>

`0.2.0-rc.1 → 0.2.0-rc.2` 之间，本插件用到的宿主接口（`webServer.register` / `tapIndex`、`connection.authenticatedUrl` / `requestRejection`、`settings.section`）一个都没变，上游只动了版本号。所以这一版**代码零改动**，只更新兼容声明，并把两个宿主 devDependency 升到 `0.2.0-rc.2` 后重跑类型检查与全部 **359** 个用例。

顺带一个好消息：`0.2.0-rc.1` 上那个「会话被内部 `overflow:hidden` 层裁掉」的回归，官方在 `rc.2` 里修掉了。同一台机器、同一条长会话实测：

| | `0.2.0-rc.1` | `0.2.0-rc.2` |
| --- | --- | --- |
| 滚动层内部被裁的层 | 1 | **0** |
| 可滚范围 | 336px | **92343px** |

因此 `mobileScrollFix` 在 `rc.2` 上已无作用对象——它每轮自检后都会整体撤销、不写任何内联样式。**开关保留、默认仍开**：在 `0.2.0-rc.2` 上零副作用，在 `0.1.7-rc.1` / `0.1.7-rc.2` / `0.2.0-rc.1` 上仍是必需的。

- 只改元数据与开发依赖，运行时行为与 `0.4.5` 完全一致，升级没有行为风险。
- 窄屏右侧栏也一并复验：390×844 下点「展开右侧栏」后按钮消失、面板铺满视口（可见面积 100%），直连 `3080` 与经代理 `3081` 逐项一致。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启一次 dsh 生效。

<h3 id="en-v0.4.6">🔌 Compatible with DeepSeek Harness 0.2.0-rc.2</h3>

Between `0.2.0-rc.1` and `0.2.0-rc.2` nothing this plugin relies on changed — `webServer.register` / `tapIndex`, `connection.authenticatedUrl` / `requestRejection`, `settings.section` all keep their signatures; upstream only bumped version numbers. So this release is **zero code changes**: compatibility metadata only, plus both host devDependencies raised to `0.2.0-rc.2` with the type check and all **359** specs re-run.

There is good news too: upstream fixed the `0.2.0-rc.1` regression where an inner `overflow:hidden` layer clipped the transcript. Same machine, same long session:

| | `0.2.0-rc.1` | `0.2.0-rc.2` |
| --- | --- | --- |
| Clipped layers inside the scroller | 1 | **0** |
| Scroll range | 336px | **92343px** |

`mobileScrollFix` therefore has nothing left to act on under `rc.2` — every round self-checks, reverts wholesale and writes no inline style. The switch **stays on by default**: zero side effects on `0.2.0-rc.2`, still required on `0.1.7-rc.1` / `0.1.7-rc.2` / `0.2.0-rc.1`.

- Metadata and dev dependencies only; runtime behaviour is identical to `0.4.5`, so upgrading carries no behavioural risk.
- The narrow-screen right sidebar was re-verified as well: at 390×844 the expand button disappears and the panel fills the viewport (100% visible), identical on direct `3080` and through the proxy on `3081`.
